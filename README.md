# Pepitra — installation

**Pepitra repère les vidéos courtes qui explosent, t'explique pourquoi elles marchent, et te prépare tout pour faire la tienne dans ta niche.**

Ce dépôt sert uniquement à **télécharger le logiciel Pepitra pour Windows**. Il ne contient pas le code de Pepitra.

## ⬇️ Télécharger

👉 **[Télécharger la dernière version de Pepitra](https://github.com/iapepitra-create/Istallation/releases/latest)**

Sur la page qui s'ouvre, dans « Assets », clique sur **`Pepitra-Setup-<version>.exe`**.

## 💻 Configuration requise

- **Windows 10 ou Windows 11**, 64 bits (presque tous les PC récents)
- 4 Go de mémoire (8 Go conseillés), environ 1 Go d'espace libre
- Une connexion internet (les IA travaillent en ligne)

Rien d'autre à installer : Pepitra contient tout ce qu'il lui faut.

## 🛠️ Installation

1. Double-clic sur **`Pepitra-Setup-<version>.exe`**.
2. Si Windows affiche **« Windows a protégé votre ordinateur »** : clique sur **Informations complémentaires**, puis **Exécuter quand même**. Ce message apparaît tant que le logiciel n'est pas encore signé numériquement (c'est prévu).
3. Choisis le dossier d'installation, puis **Installer**.
4. Pepitra se lance depuis l'icône **Pepitra** du bureau ou du menu Démarrer.

> **Windows 11 avec « Smart App Control » activé** : ce réglage de Windows bloque pour l'instant les logiciels non signés, dont Pepitra. La version signée arrivera bientôt.

## 🔑 Premier lancement : tes clés (gratuites)

Pepitra s'ouvre **sans aucune clé**. Un bandeau t'indique celles qui manquent :

- **Google Gemini** (indispensable) : regarde et analyse les vidéos — [obtenir ma clé](https://aistudio.google.com/app/apikey)
- **OpenRouter** (conseillée) : écrit les idées, prompts et accroches avec des IA gratuites — [obtenir ma clé](https://openrouter.ai/keys)
- Facultatives : Groq, YouTube, ElevenLabs

Colle-les dans **Réglages › Clés de Pepitra** : elles sont vérifiées et utilisées tout de suite.

## 📁 Tes données

Tes données et tes clés restent **sur ton PC**, dans `%APPDATA%\Pepitra`. Une mise à jour ou une réinstallation ne les efface pas.

## 🎙️ Assistant vocal « Hey Pepitra » (facultatif)

L'assistant vocal du Centre de commande demande un compte Claude personnel. Il sera proposé dans une prochaine version.

## 🗑️ Désinstaller

Paramètres Windows › Applications › **Pepitra** › Désinstaller. Tes données restent dans `%APPDATA%\Pepitra` (supprime ce dossier si tu veux tout effacer).
